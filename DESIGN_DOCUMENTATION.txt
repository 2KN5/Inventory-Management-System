
ΣΗΜΕΙΩΣΗ: Όλα τα σχόλια στον πηγαίο κώδικα είναι γραμμένα στα Αγγλικά
για να αποφευχθούν πιθανά σφάλματα μεταγλώττισης.

--------------------------------------------------------------------------------------------------

Εντολή Μεταγλώττισης:
   gcc -o program_name -IHeaders Source/*.c

--------------------------------------------------------------------------------------------------

Header Files (.h):
   - orderQueue.h: Διαχείριση παραγγελιών.
   - product.h: Δομές και συναρτήσεις αποθεμάτων.
   - utils.h: Συναρτήσεις διεπαφής χρήστη και ελέγχου εισόδου.
   - common.h: Σταθερές, βοηθητικές συναρτήσεις, κοινοί τύποι.

Source Files (.c):
   - utils.c: Σύστημα μενού και έλεγχος εισόδου.
   - product.c: Υλοποίηση διαχείρισης αποθεμάτων.
   - orderQueue.c: Λειτουργίες ουρών παραγγελιών.
   - main.c: Σημείο εισόδου και κύριος βρόχος προγράμματος.

--------------------------------------------------------------------------------------------------

Inventory:
    - Δομή: Συνδεδεμένη λίστα (linked list) ταξινομημένη κατά EAN.
    - Αιτιολόγηση: 
        * Αποδοτική εισαγωγή/διαγραφή προϊόντων.
        * Εύκολη διατήρηση ταξινομημένης λίστας για οπτική οργάνωση.
        * Δυναμική αλλαγή μεγέθους (δεν χρειάζεται προκαθορισμένο μέγεθος).

Orders:
    - Δομή: Σύστημα ουρών προτεραιότητας με 10 "κουβάδες" (OrderBucket).
    - Αιτιολόγηση:
        * Αποδοτική εκτέλεση με βάση το "priority".
        * Σύνθετες παραγγελίες με πολλαπλά προϊόντα.
        * Διατήρηση σειράς FIFO εντός ίδιας προτεραιότητας.

Οφέλη της Προσέγγισης:
    - Διαχωρισμός αρμοδιοτήτων: ξεχωριστή διαχείριση αποθεμάτων και παραγγελιών.
    - Κλιμακωσιμότητα: και οι δύο δομές μεγαλώνουν δυναμικά.
    - Ευκολία συντήρησης: κάθε δομή έχει ξεχωριστές συναρτήσεις.

--------------------------------------------------------------------------------------------------

Κύκλος Εκτέλεσης:
   main() -> mainMenu() -> runMS() -> [Επιλογή 1-5] -> Επιστροφή στο mainMenu()

Λεπτομέρειες Επιλογών:
    1. Εισαγωγή/Ενημέρωση Προϊόντος:
        * Έλεγχος EAN (4-13 ψηφία).
        * Ενημέρωση ποσότητας αν υπάρχει.
        * Προτάσεις προϊόντων για ελλιπή EAN (<13).
        * Εισαγωγή νέου αν δεν υπάρχει (Όνομα, Ποσότητα, Τιμή).
   
    2. Εισαγωγή Νέας Παραγγελίας:
        * Όνομα Πελάτη.
        * Προτεραιότητα (1-10).
        * Κωδικός Πελάτη (επιλογή βάση εκφώνησης).
        * Προσθήκη πολλαπλών αντικειμένων (EAN, Ποσότητα).
        * Εισαγωγή 0 για τερματισμό εισαγωγής αντικειμένων.
    
    3. Εκτύπωση Αποθέματος:
        * Φίλτρο (EAN, όνομα, ή *).
        * Εμφάνιση ταξινομημένης λίστας.
        * Μορφοποιημένη έξοδος σε πίνακα.
    
    4. Εκτέλεση Παραγγελιών:
        * Έλεγχος διαθεσιμότητας αποθέματος.
        * Απομάκρυνση εκτελεσμένων παραγγελιών.
        * Εκτύπωση αποδείξεων με συνολικές τιμές.
        * Επεξεργασία παραγγελιών κατά προτεραιότητα (1 -> 10).
    
    5. Έξοδος:
        * Τερματισμός προγράμματος.
        * Καθαρισμός μνήμης (inventory + orders).

--------------------------------------------------------------------------------------------------
